# Prioritised user stories

| Priority | Story | Acceptance |
|---|---|---|
| Must | As an analyst, I need metrics calculated from the movement records so I can reproduce them. | 500 records, 5.982-day mean, €199,900 sample cost; SQL and browser agree. |
| Must | As a planner, I need agent and year filters so I can inspect a relevant cohort. | Metrics, trend, table and export use the same intersection. |
| Must | As support staff, I need to inspect delayed movements so I can investigate a reason. | Clicking a reason restricts to records over five days with that reason; reset restores all records. |
| Must | As a reviewer, I need synthetic data clearly identified so I can assess the project honestly. | Data boundary is visible in the opening and methodology. |
| Should | As an analyst, I need a CSV export so I can continue the investigation. | Download includes all filtered records, not just the visible page. |
| Should | As a business analyst, I need a sensitivity slider so I can discuss assumptions. | Zero reduction reproduces baseline; only documentation-delayed movements change; no financial forecast is claimed. |
| Could | As a terminal supervisor, I need a mobile overview. | Layout fits a narrow viewport; the wide source table scrolls inside its container. |
| Won't (demo) | Connect live TOS or customs systems. | No credentials, personal data or operational side effects. |
